# Security Policy

## Reporting a vulnerability

Please open a private security advisory on this repository:

https://github.com/skillmasterai/skillmaster-skills/security/advisories/new

Do not open a public issue for a vulnerability.

## Scope

This repository contains one skill file (`skills/skillmaster/SKILL.md`) and its Claude Code plugin manifest. The hosted SkillMaster service, the console, and the server are not part of this repository and are not covered by its license.
