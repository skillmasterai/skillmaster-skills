# Security Policy

## Reporting a vulnerability

Please open a private security advisory on this repository:

https://github.com/skillmasterai/skillmaster-skills/security/advisories/new

Do not open a public issue for a vulnerability.

## Scope

This repository no longer publishes a skill (v94 retired the entry skill). The hosted SkillMaster AI service, the console, the CLI and the server are not part of this repository and are not covered by its license.
